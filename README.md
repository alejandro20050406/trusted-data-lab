# Trusted Data Lab — Observatorio de insumos odontológicos

Proyecto integrador de Análisis Estadístico para Ciencia de Datos y Calidad en los Sistemas de Información. Se propone comparar precios publicados de insumos para profesionales de Colima y Villa de Álvarez.

**Estado:** captura inicial de páginas de Imdent, Tu Universo Dental Colima y Dentalink Market México implementada y probada localmente. La programación en GitHub debe verificarse en la rama predeterminada. Se cuenta con un periodo observado, no con 36; no existe todavía un comparador funcional. La entrevista de Amaranta es simulada.
