# Trusted Data Lab — Observatorio de Abastecimiento Inteligente para Consultorios de Colima

Proyecto académico orientado al abastecimiento de insumos médicos y dentales para consultorios del estado de Colima. La máquina de captura usa el piloto odontológico de Imdent, Tu Universo Dental y Dentalink Market.

El 12 de noviembre de 2026 una ejecución local capturó las tres páginas y guardó los originales y un manifiesto en Bronce. El flujo diario de GitHub Actions está configurado; una ejecución manual anterior funcionó el 11 de noviembre, pero no se ha observado la ejecución programada. La entrevista de Amaranta es simulada.
